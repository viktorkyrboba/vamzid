# Все Для Дома — сайт магазина

Статический сайт без сервера, базы данных, cookies и сторонних скриптов.

## Структура
- `src/index.html` — исходник: разметка, стили и скрипт в одном читаемом файле. **Править здесь.**
- `img/` — фоновые фото (JPEG).
- `tools/build.py` — сборка.
- `dist/` — собранный сайт для Cloudflare Pages, `index.html` — для GitHub Pages (не править вручную).
- `404.html`, `robots.txt`, `og.jpg` (превью для соцсетей), `_headers` (заголовки безопасности для Cloudflare/Netlify).

## Хостинг
- Основной: **Cloudflare Pages** — публикует папку `dist/` из этого репозитория после каждого обновления.
- Запасной: GitHub Pages — `index.html` в корне.

## Сборка
```
python3 tools/build.py all               # dist/ (Cloudflare) + index.html (GitHub), строгий CSP по хешам скриптов
python3 tools/build.py single out.html   # один файл со встроенными картинками
```
После любой правки `src/index.html` нужно пересобрать: иначе хеши CSP не совпадут и скрипты не запустятся.

## Где что менять
- Рубрики каталога — `const MENU` в начале скрипта.
- Товары — `const PRODUCTS` (формат описан в комментарии).
- Фото карусели — блок `.gview` в разметке (по 3 фото на страницу).
- Telegram для заявок — `const TG`.
- Часы работы — объект `H` в блоке статуса «открыто/закрыто» и таблица в разделе «Контакты».

## Данные посетителей
Хранится только корзина (`localStorage`, ключ `vdd_cart`). Заказ уходит в магазин только по нажатию «Отправить» самим посетителем.

## Онлайн-заказы
Корзина → «Оформить заказ» → форма (имя, фамилия, телефон, доставка/самовывоз, адрес, оплата, комментарий, согласие).
- Пока `const ORDER_ENDPOINT=""` — сайт предлагает позвонить в магазин.
- Чтобы заказы приходили автоматически, разверните `tools/telegram-worker.js` на Cloudflare Workers,
  впишите его адрес в `ORDER_ENDPOINT` и пересоберите (`python3 tools/build.py gh`) — сборка сама разрешит подключение к этому адресу.
- Токен бота хранится только в Cloudflare (секрет `BOT_TOKEN`), в код сайта его класть нельзя.

## Отзывы и оценки на странице товара

Посетитель ставит звёзды и (по желанию) пишет имя и текст — отзыв сразу появляется на странице товара, а владельцу приходит уведомление в Telegram.
Хранятся отзывы в Cloudflare KV, доступ даёт Worker `vdd-orders` (`tools/telegram-worker.js`, адреса `/review` и `/reviews`).

Включить: Cloudflare → Storage & Databases → KV → Create (имя `vdd-reviews`); затем Worker `vdd-orders` → Settings → Bindings → Add → KV namespace, имя переменной **REVIEWS**; вставить свежий код Worker и нажать Deploy.
Без привязки KV сайт работает: форма отзыва тогда открывает Telegram с готовым текстом.
Защита: один отзыв на товар в сутки с одного адреса, не больше 5 в сутки; в KV хранится только хеш адреса, 24 часа.
Удалить отзыв: KV → vdd-reviews → ключ `r:<название товара>` → правка списка. Если переименуете товар, добавьте ему поле `id:"…"` со старым названием, чтобы отзывы не потерялись.

## Фото товаров

`python3 tools/photo.py исходное.jpg img/товар.jpg` — обрезает поля, убирает шум и артефакты JPEG, увеличивает до 800×800, добавляет резкость, делает фон чисто белым и ставит товар по центру. Исходник не меняется. Лучший результат — когда исходное фото крупное (от 800 px по длинной стороне).
